# Markdown Notes

Учебное веб-приложение для публикации Markdown-заметок с публичным просмотром, авторизованным редактированием и ограниченным сроком жизни.

[План реализации проекта](PLAN.md)

## Локальное Docker-окружение

Код приложения пока отсутствует. Окружение запускает Nginx со стандартной
стартовой страницей из Docker-образа, постоянным томом для файлов сайта
и проверкой работоспособности. Backend и база данных не создаются.

Требования: запущенный Docker Desktop в режиме Linux containers и Docker Compose.

```powershell
docker compose up -d
docker compose ps
```

Страница: http://localhost:8080. Проверка состояния: http://localhost:8080/health.
Порт доступен только с этого компьютера.

```powershell
# Логи сервера
docker compose logs --tail 100 -f web

# Остановка с сохранением файлов сайта
docker compose down

# Повторный запуск
docker compose up -d
```

Файлы сайта хранятся в томе `markdown-notes-local_site-data`.
Команда `docker compose down -v` удалит этот том вместе с его содержимым.
Настройки сервера находятся в `docker/nginx.conf`.

Контейнер работает от непривилегированного пользователя, с файловой системой
образа только для чтения, без Linux capabilities и с ограничением размера логов.
Состояние healthcheck видно в `docker compose ps`; unhealthy само по себе
не перезапускает контейнер. Политика `unless-stopped` перезапускает завершившийся
процесс. Это локальная заготовка для практической №7; публичный сервер,
HTTPS и полноценный мониторинг здесь не настроены.
